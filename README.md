# Lab Infrastructure PME

## Présentation

Ce projet a pour objectif de concevoir, déployer et documenter une infrastructure informatique complète simulant une PME.

## Objectifs

- Concevoir une architecture réseau professionnelle
- Déployer Active Directory
- Configurer DNS et DHCP
- Mettre en place des GPO
- Déployer un serveur de fichiers
- Superviser l'infrastructure
- Mettre en place des sauvegardes
- Automatiser certaines tâches avec PowerShell
